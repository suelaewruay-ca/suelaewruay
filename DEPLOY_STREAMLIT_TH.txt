ซื้อแล้วรวย — ชุดสำหรับ Streamlit Community Cloud

เริ่มต้น
1. แตก ZIP นี้ก่อนอัปโหลดไป GitHub อย่าอัปโหลดไฟล์ ZIP ทั้งก้อน
2. สร้าง GitHub repository แบบ Private และอัปโหลดไฟล์/โฟลเดอร์ที่แตกออกมา
   ให้ app.py และ requirements.txt อยู่หน้าแรกของ repository
   ต้องมีโฟลเดอร์ .streamlit, assets และ data ด้วย
3. เข้า https://share.streamlit.io/ เชื่อม GitHub แล้วเลือก Create app
4. เลือก repository และ branch ที่อัปโหลด ตั้ง Main file path เป็น app.py
5. เปิด Advanced settings เลือก Python 3.12 และตั้ง Secrets ตามตัวอย่างด้านล่าง
6. กด Save และ Deploy เมื่อเว็บเปิดแล้วเข้าสู่ระบบด้วยรหัสแอดมินที่ตั้งไว้

Streamlit Secrets
คัดลอกข้อความ 4 บรรทัดนี้ลงช่อง Secrets แล้วเปลี่ยนรหัสก่อนบันทึก:

ADMIN_PASSWORD = "REPLACE_WITH_YOUR_ADMIN_PASSWORD"
APP_PASSWORD = "REPLACE_WITH_YOUR_MEMBER_PASSWORD"
GOOGLE_API_KEY = ""
GEMINI_MODEL = ""

รหัสแอดมินกับสมาชิกต้องต่างกัน ยาวอย่างน้อย 8 ตัวอักษร แนะนำ 16 ตัวขึ้นไป
สองช่องท้ายเว้นว่างได้หากยังไม่ใช้ AI ถ้าใช้ให้ใส่ Gemini API key และชื่อโมเดลที่ใช้ได้
ค่า Secrets ใช้เริ่มต้นฐานข้อมูลครั้งแรก หลังจากนั้นเปลี่ยนค่าผ่านหน้าแอดมิน
ไฟล์ .streamlit/secrets.toml.example เป็นตัวอย่างเท่านั้น ไม่มีรหัสจริง
อย่าอัปโหลด .streamlit/secrets.toml หรือไฟล์คีย์จริงเข้า GitHub

สร้าง Service account JSON
1. เข้า https://console.cloud.google.com/ สร้างหรือเลือก Google Cloud project
2. ไป APIs & Services > Library > Google Sheets API > Enable
3. ไป IAM & Admin > Service Accounts > Create service account
   ตั้งชื่อ เช่น zani-sheet-writer
   ช่องสิทธิ์เข้าถึง Google Cloud project และผู้จัดการบัญชีเว้นว่างได้สำหรับงานนี้
   ไม่ต้องให้ Project Owner/Editor แล้วกด Done
4. คลิกบัญชีที่สร้าง > Keys > Add key > Create new key > JSON > Create
5. เก็บไฟล์ JSON ที่ดาวน์โหลดไว้เป็นความลับ แยกจากโฟลเดอร์อัปโหลดเว็บ
6. คัดลอกอีเมลบัญชีบริการ หรือค่า client_email จาก JSON
   จากนั้นเปิดชีตด้านล่าง > Share > เพิ่มอีเมลนั้นเป็น Editor

ชีตประวัติที่เตรียมไว้
https://docs.google.com/spreadsheets/d/1TCbw44oRdm8PQcatBAgATrOoo7t-nMBRUukrm7IzkF4/edit

เชื่อมประวัติจากหน้าแอดมิน
1. เปิดเว็บออนไลน์ ล็อกอินแอดมิน > หลังบ้าน > สถิติการเข้าใช้งาน
2. เปิดหัวข้อ เชื่อมต่อ Google Sheets สำหรับประวัติ
3. ใส่ลิงก์ชีตด้านบน และชื่อแท็บ ประวัติเข้าใช้งาน
   อย่าเลือกแท็บ สถิติเข้าใช้งาน ซึ่งเป็นแท็บสรุปยอด
4. อัปโหลดไฟล์ Service account JSON ที่ดาวน์โหลดจาก Google
5. ติ๊ก เปิดการส่งประวัติไป Google Sheets แล้วกด บันทึกการเชื่อมต่อประวัติ
6. กด ส่งรายการที่รอไป Google Sheets และ รีเฟรชสถานะประวัติ เพื่อตรวจผล
7. ตรวจเวลาส่งสำเร็จล่าสุด จำนวนรายการรอส่ง และข้อมูลในชีต

ระบบประวัติรุ่นนี้รับ JSON ผ่านหน้าแอดมิน ไม่ต้องแปลงเป็น TOML
ฐานสูตรสำหรับใช้งานเว็บมีอยู่ใน data/formulas_snapshot.json แล้ว

เปลี่ยนลิงก์ฐานสูตรสำหรับทีมอื่น
1. แอดมินไปที่ หลังบ้าน > ตั้งค่าฐานสูตร > เปลี่ยนลิงก์หรืออัปเดตสูตร
2. ใส่ลิงก์ Google Sheets และชื่อแท็บสูตรจริง ระบบใช้ชื่อแท็บ ไม่ใช่ gid ในลิงก์
3. เลือก Service account (ชีตส่วนตัว) และอัปโหลด JSON สำหรับอ่านสูตร
   แชร์ชีตสูตรให้ client_email เป็น Viewer เปิด Google Sheets API ในโปรเจกต์นั้นด้วย
   ครั้งต่อไปเว้นไฟล์ว่างเพื่อใช้คีย์สูตรเดิมได้
   ถ้าใช้บัญชีเดียวกับประวัติ ให้อัปโหลดไฟล์ JSON เดียวกันในเมนูสูตรอีกครั้ง
   หากชีตอ่านได้โดยไม่ล็อกอิน Google สามารถเลือก ชีตสาธารณะ แทนได้
4. กด ตรวจสอบและโหลดสูตร ดูจำนวนสูตร ชื่อแท็บ และตัวอย่าง 5 สูตรแรก
   ตารางต้องมี A1 = เลขตั้งต้น, A2:A11 มีเลข 0–9 ครบ, B1 เป็นต้นไปเป็นชื่อสูตร
   แต่ละช่องมีเลขเว้น 3 ตัวไม่ซ้ำ รองรับสูงสุด 200 สูตร ทุกสูตรต้องตรวจผ่าน
5. กด นำสูตรชุดนี้ไปใช้ เมื่อยืนยันชุดที่ตรวจแล้ว
6. สมาชิกทุกคนใช้สูตรชุดเดียวกันในแอป และได้รับชุดใหม่ในการใช้งานครั้งถัดไป
   ผลวิเคราะห์เก่าจะถูกล้างให้วิเคราะห์ใหม่ ประวัติผลจริงและบันทึกเดิมยังอยู่
7. เมื่อแก้ชีตต้นทาง ให้โหลดและนำเข้าใหม่ เว็บไม่ได้โหลด Google ทุกครั้งที่ใช้งาน
   หากอ่านไม่สำเร็จหรือสูตรผิดรูปแบบ ชุดที่ใช้งานอยู่จะไม่ถูกเปลี่ยน
8. สูตรที่นำเข้าและคีย์เก็บใน SQLite หาก Cloud ล้างข้อมูล ต้องตั้งค่าและนำเข้าใหม่
   การใส่ GOOGLE_SHEET_URL หรือ [gcp_service_account] ใน Secrets ไม่ได้ตั้งค่าสูตรนี้

การแสดงจำนวนและพื้นหลัง
- สมาชิกและแอดมินเห็นจำนวนครั้งเข้าใช้งานที่ท้ายหน้า หลังล็อกอินเท่านั้น
- นับจำนวนครั้งที่ล็อกอินสำเร็จ ไม่ใช่จำนวนบุคคลไม่ซ้ำ
- วันนี้ใช้เขตเวลา UTC+08:00
- ภาพพื้นหลังเริ่มต้นอยู่ที่ bg.png
- เปลี่ยนธีมได้ที่ หลังบ้าน > ภาพพื้นหลังและธีมเทศกาล

ข้อจำกัดข้อมูลถาวรบน Community Cloud
รุ่นนี้ยังเก็บยอดบนเว็บ ค่าหลังบ้าน สูตรที่นำเข้า คีย์การเชื่อมชีต และภาพธีมที่อัปโหลดใน SQLite
Community Cloud ไม่รับประกันความคงอยู่ของไฟล์ในเครื่อง
หาก SQLite ถูกล้าง ยอดบนเว็บจะเริ่มใหม่ และต้องตั้งค่าการเชื่อมชีต/ธีม/สูตรใหม่
รหัสและ AI จะเริ่มต้นใหม่จาก Secrets ประวัติที่ส่งสำเร็จใน Google Sheets ยังอยู่
แอปยังไม่อ่านประวัติเดิมจากชีตกลับมาสร้างยอดบนเว็บ และไม่มีฐานข้อมูลภายนอก
หากต้องการรักษายอดและค่าหลังบ้านถาวร ต้องเพิ่มฐานข้อมูลภายนอก
หรือใช้โฮสต์ที่มีดิสก์ถาวร การเปลี่ยน path SQLite บน Community Cloud อย่างเดียวไม่พอ

หากติดปัญหา
- ยังไม่เปิดให้เข้าใช้งาน: ตรวจ ADMIN_PASSWORD ใน Streamlit Secrets
- แอปเปิดไม่ได้: ดู Cloud logs ตรวจ requirements.txt, Python 3.12 และไฟล์ครบ
- เขียนชีตไม่ได้: ตรวจ Sheets API และแชร์ให้ client_email เป็น Editor
- JSON ไม่ผ่าน: ใช้ JSON จาก Service account > Keys ไม่ใช่ OAuth client JSON
- หัวตารางไม่ตรง: ใช้แท็บ ประวัติเข้าใช้งาน และคงหัวตารางเดิม
